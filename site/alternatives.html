Alternatives

Other ways to read Markdown in a terminal

vellum is not the only option, and for some jobs another tool fits better. These are the established ones. Check each project for its current features.

glow

Go. Renders Markdown on the command line, with a TUI for finding and browsing Markdown files.

Repository

mdcat

Rust. cat for Markdown: prints the rendered document to the terminal, with images on terminals that support them. Output, not an interactive viewer.

Repository

Frogmouth

Python, built on Textual. A Markdown browser with a table of contents, history and bookmarks, and can open files from the web.

Repository

mdless

Ruby. Formats Markdown for the terminal and pages it through less.

Repository

bat

Rust. A cat clone with syntax highlighting. It highlights Markdown source rather than rendering it. vellum uses it for code view when no editor is set.

Repository

Rich CLI

Python. A command-line front end to the Rich library that prints Markdown, source code, CSV and other formats with formatting.

Repository

When vellum is the better fit

  • You want to scroll, search and follow links in one full-screen view rather than print the file.
  • You copy commands out of READMEs, often over SSH: select a block, press y, and it is in your local clipboard.
  • You want images inline and no network requests unless you ask for them.
  • You want a single binary with no runtime to install.

When another tool is

  • You want rendered Markdown in a pipe or a script: a printing tool such as mdcat or glow fits.
  • You browse a whole folder of notes: glow and Frogmouth are built around finding files.
  • You want to see the raw source with highlighting: use bat.
