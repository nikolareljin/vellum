Installing vellum

vellum is a single binary with no runtime dependencies. Pick the method that suits your platform. Every release is on the GitHub releases page.

PlatformMethods
macOS (Apple Silicon, Intel)Homebrew, tarball, cargo
Linux x86_64Homebrew, .deb, tarball, single binary, cargo
Linux arm64 and otherscargo, from source
Windows x86_64vellum-windows.exe, cargo, or Linux in WSL

Homebrew (macOS and Linux)

The tap installs a prebuilt binary: arm64 or x86_64 on macOS, x86_64 on Linux.

brew tap nikolareljin/tap
brew install vellum

Upgrade with brew upgrade vellum, remove with brew uninstall vellum.

Debian and Ubuntu (.deb)

Each release carries an amd64 package, named like vellum_0.7.0-1_amd64.deb. Download it from the releases page, then:

sudo apt install ./vellum_0.7.0-1_amd64.deb

It installs /usr/bin/vellum. Remove it with sudo apt remove vellum.

Prebuilt tarballs

Each release has three archives named vellum-<version>-<target>.tar.gz, each holding the vellum binary:

TargetFor
macos-arm64macOS on Apple Silicon
macos-x86_64macOS on Intel
linux-x86_64Linux x86_64 (glibc)
 
tar -xzf vellum-0.7.0-linux-x86_64.tar.gz
install -m 755 vellum ~/.local/bin/vellum

~/.local/bin must be on your PATH.

Single binaries

Releases also carry bare binaries, x86_64 only:

  • vellum-linux: Linux, linked against glibc.
  • vellum-musl: Linux, statically linked with musl. Use it on Alpine or an old glibc.
  • vellum-windows.exe: Windows, see below.
chmod +x vellum-musl
mv vellum-musl ~/.local/bin/vellum

Windows

Download vellum-windows.exe from the releases page, rename it to vellum.exe and put it in a folder on your PATH. Run it in Windows Terminal. Copying code uses clip.exe.

The Windows build is cross-compiled and less tested than the Linux and macOS ones. One known gap: links to web pages do not open a browser on native Windows. Under WSL, vellum is a normal Linux program, any of the Linux methods above work there, and copying still reaches the Windows clipboard through clip.exe.

Cargo (any platform with Rust)

Needs Rust 1.90 or newer. This builds the latest code on the default branch:

cargo install --locked --git https://github.com/nikolareljin/vellum --bin vellum

To build a specific release, add --tag 0.7.0. The binary goes to ~/.cargo/bin.

From source

git clone https://github.com/nikolareljin/vellum
cd vellum
cargo build --release
./target/release/vellum README.md

On Linux and macOS the repository also has an install script. It builds a release binary and copies it to ~/.local/bin:

./install                       # build and install, or upgrade
./install --prefix /usr/local   # install to /usr/local/bin (may need sudo)
./install --uninstall

To build a .deb yourself:

cargo install cargo-deb --locked
cargo deb
sudo apt install ./target/debian/vellum_*.deb

Optional tools
